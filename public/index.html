        (!) Three Windows settings for a node that runs on its own
        
                    
          
                  1. Turn off hibernation. A hibernating node stops answering. Windows also keeps a hidden file for it about three quarters the size of this PC's RAM. In Command Prompt, run as administrator, type powercfg /h off (powercfg /h /size shows how big the file is).
                    2. 
          
                  2. Sign in automatically. For a node with no screen or keyboard (headless). After a restart Windows waits at the password screen, and TOMLIN does not start until someone signs in. Press Windows + R, type netplwiz, untick Users must enter a user name and password to use this computer, and enter the password once. If that box is missing, turn off Settings › Accounts › Sign-in options › For improved security, only allow Windows Hello sign-in first. Anyone at the PC can then sign in, so use it only for a PC in a safe place.
                    3. 
          
                  3. Stop the "finish setting up your device" and backup reminders. Windows can show a full-screen prompt after an update or start, and TOMLIN does not answer behind it. In Settings › System › Notifications › Additional settings, untick the options about suggesting ways to finish setting up this device and about tips and suggestions. Names differ a little between Windows versions.
