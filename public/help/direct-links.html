Direct links between PCs

Two linked PCs copy a model straight to each other.

Two PCs linked to the same host can copy a model straight to each other over the home network, without it passing through the host. Each PC's owner must tick Let PCs my host introduces connect to this PC directly, and the PC that receives a model Accept models from linked PCs (see Sharing and cluster permissions). The other ticks still decide what such a PC may do, and the PCs the host names are the only ones that may connect.

On the host

Network, Direct links between PCs: pick One PC and The other PC and press Introduce them. The host can check a link, end it, and order a model copied between the two; the host only orders and follows, and the receiving PC pulls the file from the other and checks it against the original before it is used.

On a node

The node's owner sees the direct links that PC has, and can remove one. Unticking the switch ends them all.
