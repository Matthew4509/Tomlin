The Bridge: privacy and trouble

What leaves this PC, if something goes wrong, and where its data is.

What leaves this PC

Nothing about you or your projects goes to the internet unless you send it with Push live (off until you turn it on): then the project's files, and its Live secrets, go to the web host you connected, and nowhere else. The only other requests that leave for the internet are plain page requests to the live addresses you add under Hosted live, and, only if you tick it, one request a day to GitHub for the newest Git version. A project you tick under Copies on my other PCs goes only to your own linked PCs, over your home network and encrypted. Tokens are counted from the AI transcripts already on this PC; they are read, never changed or sent.

If something goes wrong

  • The page says Connection lost: TOMLIN stopped. Start it again (its desktop icon, or Start TOMLIN.cmd); this page reconnects by itself.
  • A project shows "No start command": click it for a prompt to paste into your AI, which adds a "start" to the project's own project.json. Or list it in projects.json in the Bridge's data folder (TOMLIN's home, data\bridge; see README.md).
  • Your folders or prompts are suddenly back to the start: the file that held them could not be read. It was kept in the Bridge's data folder (TOMLIN's home, data\bridge) as settings.damaged-…json or prompts.damaged-…json; close TOMLIN, copy back what you need, and start it again.
  • Git error on a project: click the mark; it says why (git not installed, folder owned by another account, or git settings that could run a program).

Where its data is

Its settings, audits, prompts and lists are in TOMLIN's home, in data\bridge, and go with TOMLIN's own backups. Uninstalling TOMLIN removes the Bridge with it.
