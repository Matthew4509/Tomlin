Jobs

A goal turned into steps you read and change before anything runs.

A job turns a goal into small steps you read and change before anything runs. On Home, Lets create a project takes a project name, a mini description (optional) and the prompt, and makes the project's folder inside the workspace folder, named after the project (with the date and time when it has no name); Staff, a list of each hire as name - software - PC, picks who gets it (Default is the strongest worker available; a hire on a Backups only PC is not listed), and Lets go! sends them the prompt as a normal message, in a chat in the new project: no plan, and the first answer is also saved as a file in the project folder.

Advanced / job planner, beside it, asks a few questions and lets you pick the look, then makes a plan in steps. Each step sees only its brief and its files, and code checks every answer.

In Jobs, the left column has each job's Overview, its steps (press one to read and change it) and See all. The Overview holds the Scope card and the design brief (the copy icon copies one; the pencil changes it, with Cancel and Save), Choose a Project manager, and Roles: for the Coder and the Writer, assigned is the hire you pick, not assigned means the project manager does those steps, and default is a hire in that role, else the project manager; for Auditing (the reviewer and the end-of-job report), assigned is the hire you pick, not assigned means nobody audits, and default is the strongest worker available. What you expect of the final audit goes to the auditor with the end-of-job report.

Run the next step saves nothing until you press Save; LETS GO!!! runs the rest, saving each step that passes the checks and stopping at the first that does not.

Web, in the Overview, lets the job's steps search the web and read pages, as Web does in a chat; what each step looked up is said in the job's room.
