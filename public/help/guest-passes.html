Guest passes

Let another PC use chosen models, for a day, a week or no limit.

A guest pass lets another PC use the models you tick, on the PCs you tick (this PC when it is a node, and the nodes linked to it), and pull TOMLIN updates where "Let linked PCs pull TOMLIN updates from here" is on. Nothing else: no copies, backups, settings, runners or cluster. Its staff and chats stay on that PC. Each node keeps its own copy, so a pass works while this PC is off, and ends on its date even on a node this PC cannot reach. The owner of each node can see what a guest runs there.

Making a pass

  1. Network, Guest passes, Create a guest pass.
  2. Type the Name of person this is for and pick the Length: 1 day, 1 week or No limit.
  3. Under PCs and the models a guest may use on each, tick the PCs and the models.
  4. Press Make pass, and give the guest the code (such as ABCD-EFGH).

On the guest's PC, the code goes in the Setup code or guest pass code box, on Network, Add another PC. Add a node, beside Create a guest pass, takes you to adding a PC.

Limits

  • Host goes first: work from this PC's own (admin) links runs before guests' (first come among each).
  • A guest's answer, up to (tokens) and A guest's prompt, up to (characters) cap what one guest request may ask for.
  • A guest can never update, turn a PC off or change what is on it.
