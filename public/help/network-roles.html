Admin PC, node and storage

What each PC can be, and where models and backups are kept.

A PC is not one thing or another: it can be an admin PC, a node and a network backup all at once. Settings, This PC has a This PC is card with a switch for each; Network has a tab for each: This is an admin PC (it connects to nodes), This is a node and Backup, model and LLM storage.

An admin PC

Any PC becomes an admin when it links other PCs (Network). The PC that links to a node becomes that node's admin, its host. Your staff, their memory and their chats stay on the admin PC; a node only loads the model and answers (or draws). A linked host is trusted like an administrator, but only for what the node's owner has ticked: see Sharing and cluster permissions.

A node

On a node, Enable this PC as a node is on (a node must have the app lock, so it asks for that PIN first). It has a name, a Setup Code (and New code for another), and an address and port other PCs use (8741 unless something else uses it). Every model on it can be used by the PCs linked to it: chat models answer, picture models draw. Several PCs can link to one node; it answers one at a time (At once, under Port, PIN and slots, can give a model more than one slot, each keeping its whole context, so it needs more memory; it takes effect when the model loads next). To add one, see Adding a PC; to keep one running on its own, Windows settings for a node.

A network backup (storage)

A PC with Enable backups ticked keeps copies of the projects and restore points of the PCs linked to it (see Backups and restore points); on the This PC card it is the switch A network backup, and it needs the node switch on. A linked PC can also be marked Backups only on its card on the main PC: no staff, chats, jobs or pictures run there, and no model is copied to it.

Where models and backups are kept

  • Models are kept in: TOMLIN's models folder in your user folder, or the folder you chose. Change folder or drive opens a box to pick another; new downloads go there. The Models folder form is also under Models, Import models (Where models are kept), which can move the models already there to the new folder. The list of models on this PC is folded: press Show models. Under it, how much room is free, and Free up space.
  • Backups from other PCs are kept in: a folder inside TOMLIN's folder, with one folder for each linked PC, or the folder you chose. It can be changed the same way.
  • TOMLIN refuses a whole drive, a folder given without its drive, a folder inside its own program, data, backups or models folders, a network path, and a drive formatted as FAT. A folder cannot be changed while backups are being kept in the current one.

Drive jobs: Main model storage and Backup storage

The Network map is a short overview of your PCs. Under them, an arrow leads to Model backups and Project backups: which PCs keep them and the room left, each with Add. Drives and what they keep are set on the Network Storage page (left panel): two tiles, Main model storage and Backup storage, each with + Add to pick a drive on any PC:

  • Main model storage: a copy of models, kept but never loaded from, so a model can be had again without the internet.
  • Backup storage: restore points and project backups.

A drive can have both jobs; a drive with no job is not used. A linked PC's drive can be given a job only when its owner has turned on the matching permission: Accept models from linked PCs for Main model storage, Enable backups for Backup storage. The Network Storage page does the same with two tiles and + Add.

Each tile is set to Extended or Duplicate:

  • Extended: each file is kept once, and every drive's room adds up (two 2 TB drives: 4 TB). If a drive fails, what was on it is lost.
  • Duplicate: two copies of each file, always on two different PCs, so half the room (two 2 TB drives on two PCs: 2 TB). If one PC fails, nothing is lost. Two drives in the same PC do not count: the box warns about it.

Main model storage starts as Extended and Backup storage as Duplicate. Each file stays a normal, whole file on a normal drive, so a drive taken out can be read on any PC. Main model storage is filled from the Models page (To, Main model storage): each PC downloads its copy into a folder named TOMLIN Model store on its drive (see Models, The downloads list). Backups are not put in Backup storage yet.

Keep 2 to 10 GB free on a node, and remove a model from the main PC's disk only after the question about where else it is held (see Copying models between PCs).
