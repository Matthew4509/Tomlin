Chat permissions: what a chat may do

Ask first or Auto for files and web, the coding, research and screen roles, standing rules.

Settings, Chat permissions says what a chat's model may do on its own. Pages on this PC or your home network are never opened, and files outside the chat's folder are never touched, whatever is chosen there.

Agents' standing jobs have their own tools, approved per job on the Agents page (see Agents: standing jobs): nothing on this page gives a standing job more, or less.

Files and Web: Ask first or Auto

Ask first: the chat asks you the first time in each answer. Auto: it goes ahead without asking. Files means listing, reading and saving files in the chat's folder; Web means searching and opening pages (see Web).

The roles

  • Coding role: in a chat whose folder is listed under Coding folders, read git, and run a named command when allowed. Coding folders: one folder a line (the whole path); only a chat that works in one of them gets the coding tools. Your named commands: one a line, as name=command; it must start with node, npm, npx, python or php, with no pipes, && or redirects. With none of your own, test, build, lint and typecheck come from package.json. Even with Run at Allowed, a command asks first, naming the files, whenever a model has saved files in that folder since you last allowed one there (in this answer or any earlier one, by a chat, an agent or a job step): a command runs as you, with your whole PC in reach, so you see what it may run before it does. Your yes clears that list; what you type yourself in Files never adds to it.
  • Research role: in a chat with Web on, read more pages, save notes with their sources, and suggest findings. A finding is kept only when you press Save under the answer.
  • Screen roles: Windows it may look at, one a line: the window's whole title, with * for any letters, and its program before a | if you wish. A window that is not listed is never named, read or touched. With none listed there are no screen tools.

Standing rules

One rule per line, added to every message a model gets and to the Connect Claude prompt. A rule is a request, not a lock. Checked in code as well: files outside the chat folder are never touched, no tool can delete a file, and a save that would empty or gut a file (or hold a password or key) is refused. Reset to the 12 defaults puts the starting rules back.

Web search

Which engine a chat with Web on searches with (DuckDuckGo with no key, Brave Search with your own key, or a SearXNG of your own) is set under Settings, Data and lock, Web search.
