Bootable USB

Run TOMLIN on a diskless node: a USB stick that starts any PC as a linked node.

Settings, Bootable USB makes a stick that starts a PC into TOMLIN with no Windows and nothing written to its own disk. The PC is then an ordinary linked PC: chats run on it, guest passes can be made for it, and it can be part of a cluster. Take the stick out and switch the PC off, and it is as it was.

The admin key

The page makes this PC's admin key once. It never leaves this PC: it is not shown, not written to any stick, and not in a restore point sent to another PC. Mint gives each stick an identity of its own instead, so no two sticks are the same.

  • A PC started from one of your sticks links only to this PC: it checks that this PC signed the request with the admin key. Anyone else holding the stick, or a copy of it, cannot link to it.
  • This PC links only to the sticks on its own list, each proven by its own identity, with no setup code and no PIN.
  • One admin per stick. Minting a stick again on another admin PC makes it that PC's, and the old admin's link to it ends.

Sticks minted here

The page lists every stick minted on this PC: its name and id, when it was minted, the PC started from it, and Last seen, the last time this PC heard from that PC (linked, or found by a scan). If a stick goes missing, press Mark lost: this PC removes its link and never links it again, so a copy of it reaches nothing. Found undoes it.

If this PC is lost or replaced, press Make a new admin key on the new admin PC and mint every stick again there.

The four steps

  1. Download Rufus (it's free) from rufus.ie. Rufus is needed to image the usb drive.
  2. Download the Linux ISO: the page downloads Debian 13's live image with no desktop into your Downloads folder, and checks it against its SHA-256. Get the parts downloads what Mint adds: Node.js and llama.cpp for Linux (the same build as this PC's runners, so a cluster's parts match) and the picture tools' Linux part. Tick the CUDA build only for NVIDIA RTX 20 series cards and newer.
  3. Use Rufus to image the USB drive: the stick, the ISO, a persistent partition of about a third of the stick, then START and "Write in ISO Image mode".
  4. Select the stick and Mint: pick the stick on the page, name it, and press Mint.

Starting a PC from the stick

Put the stick in, with a network cable, and pick it in the PC's boot menu (F9, F12 or Esc on most PCs). TOMLIN node starts by itself after 5 seconds. The first start takes a few minutes. The screen then shows the PC's address and its admin.

With an NVIDIA card, start TOMLIN node (install NVIDIA driver once, needs a network) once, with Secure Boot off in the PC's firmware. Without it, the card is not used and the PC lends its processor and memory. AMD and Intel graphics use Vulkan with no driver to install.

Adding it

On this PC: Network, Add another PC, Find PCs on my network. A PC started from a stick minted here says "Made with your admin key": press Add, or Add all for several. It then shows under Linked PCs like any other.

What it allows at first

A stick PC starts with node mode on and these ticks: take models sent to it, be tested and have its run settings changed, be part of a cluster, and be turned off from here. Allow unencrypted cluster links is off unless ticked at Mint. Change them later under Network, the PC, Sharing permissions: a stick PC has no app lock, so its admin's link stands for its PIN.

Best settings per kind of hardware

At the foot of the page, Read lists every linked PC by its kind: the same processor, memory and cards. For each model, the fastest speed found on that kind is kept with its run settings, and each PC's own speed is shown beside it. A twin under 85% of the best is marked: it usually has bad RAM, a hot card or the wrong driver. Use on its twins puts those settings on every other PC of the kind.

Ports and the firewall

A stick PC listens on its link port (8741 unless changed). Its start script lets that port, and a cluster's ports, answer the home network only; TOMLIN also refuses any address outside it. Nothing needs opening on this PC: it calls the stick PC, not the other way round.

Updates

A stick PC runs the TOMLIN on its stick, so it takes no update sent from here. To update it, press Mint again on the same stick and start the PC from it again: its settings, links and models are kept on the stick's persistent part.
