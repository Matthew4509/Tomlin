The Bridge: folders, audits and prompts

Working folders, the audit list and private details, saved prompts.

  • Folders: your working folders (every folder inside one is a project), projects added one by one, and projects removed from the list (bring one back here). Add working folder opens the Windows folder picker.
  • Audits: the latest audit of each project. Private details… holds the details about you (email, phone, street, full name) the audit looks for in what you would publish. A detail is typed once and never shown again; the audit shows only its label. Check a skill… checks a Claude Code skill, plugin or agent folder before you install it: paste its SKILL.md, or choose its folder or .zip / .skill file. It answers Do not install, Read these first or No known attack found (never "safe"), and lists the scripts and hooks it runs, the services it talks to and the keys it reads. Nothing in it is run or sent anywhere. Every audit also reads a project's own AI agent files (CLAUDE.md, AGENTS.md, skills and their scripts, hooks, permissions, MCP servers).
  • Prompts: prompts you use again and again, a tile per category. Click a tile for its prompts, then Copy, Start (to one of your staff, in TOMLIN), Edit (which can move it to another category) or Remove. New category and Add prompt sit above the tiles; inside a category, Rename category and Delete category (which deletes its prompts, and says how many first). Words in [brackets] are yours to fill in. Kept on this PC only.
