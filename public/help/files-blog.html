Files and the blog writer

Plain text files in your workspace folder, and posts drafted for you to edit.

Settings, Files and blog writer opens plain text files in one folder you choose, the workspace folder. Nothing outside it is touched; saving keeps the old version beside it, with .bak on the end of its name.

Files

  • Workspace folder (empty = the default one), then Use this folder. It is where TOMLIN keeps its own work: every project made with Lets create a project, and the files your staff write and save.
  • New file name and New file make one; open one from the list, edit it and Save.
  • Add last chat answer puts the chat's last answer in the open file, and Ask the chat about this file hands it to the chat.
  • Save on a code block in a chat puts the code in this folder (Replace when the file is there; the old one is kept as .bak): see Chats and saving your work.

Blog writer

The chat model connected now (Connect at the top of a chat) drafts a post in the tone you pick. Type what the post is about, who it is for (optional) and about how many words (150 to 1200, 400 to start), pick a Tone and press Write the post; Stop keeps what is written so far. Read it, edit it, give it a title, then Save into the workspace (saving again writes over the same file). The tone starts from the chat's.

A picture is optional: Add a picture to this post writes a picture prompt from the post and opens the Send to card with it, so you see it before it is drawn; the picture, drawn by an artist or the picture model connected here, is added to the post. See Getting a good picture (Mode "Blog / photo").
